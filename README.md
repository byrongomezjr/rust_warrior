# Rust Warrior 🛡️🤺

[![Rust](https://img.shields.io/badge/Rust-1.75.0-orange.svg)](https://www.rust-lang.org/)

An immersive and practical adventure game developed for the sole purpose of acquiring more knowledge in Rust. This game combines traditional text-based adventure mechanics with a modern GUI interface.

## 🎮 About

This game is inspired by [WarriorJS](https://warriorjs.com/), reimagined in Rust with additional features and a graphical interface.

## ✨ Features

- GUI-based interface using egui
- Text-based adventure mechanics
- Location-based exploration
- Inventory system
- Save/Load game functionality
- Command system for game interactions

## 🚀 Getting Started

### Prerequisites

- Rust (latest stable version)
- Cargo (comes with Rust)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/byrongomezjr/rust_warrior.git
cd rust_warrior
```

2. Build and run the game:

```bash
cargo run
```

3. Follow the on-screen instructions to play the game.

## 🎯 How to Play

Available commands:
- `help`: Show available commands
- `look`: Look around your current location
- `inventory`: Check your inventory
- `go <direction>`: Move in a direction (north, south, etc.)
- `save`: Save your game
- `load`: Load your game
- `quit/exit`: Exit the game
